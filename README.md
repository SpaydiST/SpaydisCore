# SpaydisCore

Плагин для Paper-сервера выживания со своей атмосферой: странные мобы, аллергия на незерит, измерение Лимбо для погибших игроков, проклятие нежити и режим шизофреника.
Автор: **Spaydis**.

- Платформа: Paper (`api-version 26.3`), Java 25
- Дескриптор: только `paper-plugin.yml`
- Языки сообщений: русский, английский, немецкий (по локали игрока)
- Мягкие зависимости: SMPRevive (воскрешение из Лимбо) и Simple Voice Chat (эхо в Лимбо). Без них плагин работает, соответствующие функции отключаются.

## Возможности

| Функция | Кратко |
|---|---|
| Лимбо | Отдельное измерение для умерших игроков: бесконечный цикл, звёзды, структуры, фразы из обычного мира, самопроизвольное возвращение |
| Аллергия на незерит | Развивается от долгого ношения незеритовой брони, чихание, тошнота, отбрасывание, выброс незерита |
| Проклятие нежити | Можно есть только гнилую плоть, яд и голод не действуют, солнце жжёт, зомби не трогают, зелья работают наоборот |
| Режим шизофреника | Звуки, мобы-призраки и пропадающие блоки видит и слышит только выбранный игрок, плюс фальшивый удар без урона |
| Админ-меню | `/sc menu` — GUI для управления всем перечисленным |
| Особые имена мобов | `jeb_`, `toni_klark`, `Meneleet`, `Spaydis`, `Rereler` |
| Зомби с кирками | Под землёй зомби могут появиться с кирками |
| Сломанная бирка | После смерти именованного моба выпадает сломанная бирка |
| Сообщения Warden | Свои сообщения о смерти от Warden |
| Порталы | Режимы портала в Незер и в Энд: выключен, «открытие» (анимация), обычный |
| Лимбификация | Особая обработка предметов и урона для игроков в Лимбо |
| `/enchantfont` | Шрифт зачарований для предметов |

## Установка

1. Скачайте `SpaydisCore-<версия>.jar` из раздела Releases (или соберите сами).
2. Положите jar в `plugins/` сервера Paper.
3. Положите датапак из папки `spaydiscore_datapack/` в `world/datapacks/`. Он добавляет измерение `spaydiscore:limbo`.
4. Перезапустите сервер. Перезагрузка `/reload` не подходит из-за датапака.
5. По желанию установите SMPRevive и Simple Voice Chat.

После первого запуска появятся `plugins/SpaydisCore/config.yml` и файлы данных (`undead.yml`, `schizophrenia.yml` и другие).

## Сборка

```bash
./gradlew build
```

На Windows: `gradlew.bat build`. Готовый jar лежит в `build/libs/`. Версия задаётся в `gradle.properties`.

Регрессионные тесты запускаются вместе со сборкой. Они проверяют, что дескриптор плагина корректен и что во всех языковых файлах (`en`, `ru`, `de`) одинаковый набор ключей.

## Команды

Основная команда: `/spaydiscore`, сокращение `/sc`. Все подкоманды требуют права `spaydiscore.admin`.

| Команда | Что делает |
|---|---|
| `/sc reload` | Перечитать конфиг и языки |
| `/sc list` | Список активных цикличных сущностей |
| `/sc stop` | Остановить циклы цвета |
| `/sc nether <off\|opening\|on\|status>` | Режим портала в Незер |
| `/sc end <off\|opening\|on\|status>` | Режим портала в Энд |
| `/sc allergy give <игрок> [стадия]` | Выдать аллергию |
| `/sc allergy remove <игрок>` | Снять аллергию |
| `/sc undead give\|remove <игрок>` | Выдать или снять проклятие нежити |
| `/sc undead list` | Кто проклят |
| `/sc schizo give\|remove <игрок>` | Включить или выключить режим шизофреника |
| `/sc schizo list` | Кто в этом режиме |
| `/sc limbo enter <игрок>` | Принудительно отправить игрока в Лимбо |
| `/sc limbo leave <игрок>` | Вернуть игрока из Лимбо |
| `/sc limbo skip <игрок>` | Пропустить ожидание отторжения |
| `/sc limbo spectate` | Админ в Лимбо переключает наблюдение (спектатор), оставаясь «в Лимбо» |
| `/sc limbo stars <on\|off\|low\|normal\|high\|status> [игрок]` | Звёзды в Лимбо |
| `/sc limbo phrases <normal\|barrel\|status>` | Режим воспроизведения записанных фраз |
| `/sc limbo status` | Состояние Лимбо |
| `/sc menu` | Админ-меню |
| `/sc debug limbo …` | Отладочные события Лимбо |
| `/enchantfont` | Шрифт зачарований, доступен всем |

Подсказки по аргументам работают через Tab.

## Настройка

Все параметры находятся в `config.yml` и применяются командой `/sc reload`. Основные блоки:

- `features.*` — переключатели функций (`limbo`, `netherite-allergy`, `undead-curse`, `schizophrenia`, `jeb-shulker` и т. д.).
- `limbo.*` — цикл, структуры, звёзды, звуки, отторжение, `send-unknown-players`.
- `netherite-allergy.*` — время до развития, интервалы чихания, отбрасывание.
- `undead-curse.helmet-damage-interval-seconds` — как быстро шлем изнашивается на солнце.
- `schizophrenia.*` — задержки между звуками, призраками, пропавшими блоками и фальшивыми ударами.
- `zombie-pickaxe.*`, `meneleet.*`, `spaydis.*`, `breeding-prevention.*`, `broken-nametag.*`, `warden-death.*`.
- `language.*` — язык по умолчанию и список поддерживаемых.

Тексты находятся в `lang/en.yml`, `lang/ru.yml`, `lang/de.yml`. Цветовые коды пишутся через `&`.

## Подробно о функциях

### Лимбо

Измерение `spaydiscore:limbo` задаётся датапаком. Игрок попадает туда после смерти (если включена функция) или по команде.

- **Цикл.** Дойдя до внешнего радиуса, игрок переносится на противоположную сторону. Расстояния ненадёжны.
- **Структуры.** Несколько общих структур по кругу, которые периодически переезжают.
- **Атмосфера.** Звёзды из частиц и невидимых источников света, индивидуальные фоновые звуки, записанные фразы из обычного мира.
- **Одиночество.** Если рядом никого нет, через заданное время игрока подтягивают к другому игроку.
- **Отторжение.** Через заданное время Лимбо отпускает душу и возвращает игрока в мир.
- **Эхо голоса.** При наличии Simple Voice Chat голос в Лимбо звучит эхом.
- **Принудительный вход.** `/sc limbo enter <игрок>` отправляет любого игрока, даже живого.
- **Админ-спектатор.** Админ, умерший в Лимбо, может выйти в режим наблюдателя через `/sc limbo spectate`. Он по-прежнему считается находящимся в Лимбо, и его можно воскресить.
- **Новые игроки.** Игроков, неизвестных SMPRevive, отправляют в Лимбо как новичков (`limbo.send-unknown-players`). Админов это не касается.

### Аллергия на незерит

Долгое ношение незеритовой брони (по умолчанию 120 секунд) вызывает аллергию. Она остаётся **навсегда**, в том числе после выхода с сервера.

1. Стадия 1: периодическое чихание и тошнота при ношении незерита.
2. Стадия 2: незерит в инвентаре вызывает частое чихание, сильное отбрасывание и выброс всех незеритовых предметов.

Админ может выдать или снять аллергию командой.

### Проклятие нежити

`/sc undead give <игрок>` делает игрока нежитью:

- Можно есть **только гнилую плоть**. Остальная еда, торты и свечные торты запрещены.
- Яд и голод не действуют.
- Под открытым небом днём игрок горит. Ночью, в тени и в воде не горит.
- Шлем защищает от огня, но понемногу ломается.
- Зомби, хаски и другие зомби-мобы не атакуют игрока.
- **Зелья работают как на нежити, то есть наоборот.** Лечение ранит, вред лечит.
- **Регенерация работает как отравление.** Эффект и значок остаются обычной регенерацией, но каждый импульс отнимает здоровье вместо того, чтобы добавлять. Отнимает не ниже 1 HP.

Состояние сохраняется в `undead.yml`.

### Режим шизофреника

`/sc schizo give <игрок>`. Всё ниже видит и слышит только этот игрок, остальные ничего не замечают.

- **Звуки.** Случайные звуки поблизости.
- **Мобы-призраки.** Зомби, хаски, скелет, крипер, паук. Иногда приходит один, иногда смешанная группа. Идут прямо к игроку, не горят, никого больше не замечают. Дойдя, замахиваются и исчезают. Если ударить призрака, он тоже исчезает. Вреда они не наносят, крипер не взрывается. Для проклятых нежитью зомби-типы исключаются.
- **Пропадающие блоки.** Блоки рядом ненадолго исчезают, но только на экране этого игрока, а потом возвращаются.
- **Фальшивый удар.** Примерно раз в 10 минут игрок слышит звук урона и видит тряску экрана. Здоровье, отбрасывание и скорость не меняются.

Состояние сохраняется в `schizophrenia.yml`. Частоту событий можно менять в `config.yml`.

### Админ-меню (`/sc menu`)

Сундучное GUI с экранами «Главная», «Игроки» и «Игрок».

- Главная: режимы порталов, перезагрузка конфига.
- Игрок: отправить в Лимбо или вернуть, пропустить ожидание, наблюдение, аллергия, нежить, шизофрения, телепорт.

Права проверяются при каждом клике.

### Особые имена мобов

| Имя на бирке | Эффект |
|---|---|
| `jeb_` | Шалкер переливается цветами |
| `toni_klark` | Шалкеры и овцы циклично меняют серые оттенки |
| `Meneleet` | Моб агрессивен ко всем (настраивается) |
| `Spaydis` | Моб не атакует никого, кроме боссов |
| `Rereler` | Моб не размножается |

После смерти любого именованного моба выпадает сломанная бирка. Если моб приручён, она достаётся хозяину.

## Интеграция с SMPRevive

SMPRevive подключается через рефлексию как необязательная зависимость. Если он установлен:

- Лимбо воскрешает игроков через его API.
- Игроки, которых SMPRevive не знает, считаются новичками и попадают в Лимбо.
- Полная сцена воскрешения включается параметром `limbo.rejection.full-revival`.

Если плагина нет, воскрешение выполняется по таймеру отторжения.

